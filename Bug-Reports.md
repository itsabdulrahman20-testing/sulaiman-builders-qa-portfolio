Purpose

This document records defects identified during manual testing. Each bug report includes steps to reproduce, expected and actual results, severity, priority, and status.

Bug Report Template

* Bug ID: BUG001
* Bug Title: Short description of the issue
* Environment: Device, operating system, and browser
* Preconditions: Conditions required before testing
* Steps to Reproduce:
    1. Open the website.
    2. Navigate to the affected section.
    3. Perform the action that causes the issue.
* Expected Result: Describe what should happen.
* Actual Result: Describe what actually happens.
* Severity: To be determined based on impact
* Priority: To be determined based on urgency
* Status: Open
* Evidence: Screenshot or screen recording, if available
